Opening the File Browser

You can open the file browser in a few ways:

  • Context menu — right-click any tile and select "File Browser".
  • suwu open — from a terminal, run suwu open . to open the current directory.
  • Keyboard — use the tiling WM shortcuts to create a new tile, then switch its type.

Navigation

  • Click a directory to enter it.
  • Click the breadcrumb trail at the top to jump to any parent directory.
  • Click .. to go up one level.
  • Sort by name, size, or modification time using the column headers.

File Actions

  • Download — click the download icon next to any file to save it locally.
  • View — click a file to open it in the File Viewer tile.
  • Open in terminal — right-click and select "Open in terminal" to launch a shell in that directory.

Keyboard Shortcuts

Action Shortcut
Navigate up Backspace
Open selected Enter
Go to root Ctrl+Home
Refresh listing Ctrl+R

Hidden Files

Toggle hidden files (dotfiles) with the eye icon in the toolbar, or press Ctrl+H.

Tip

Open a file browser tile next to your terminal tile for quick reference while coding — navigate on the left, edit on the right.
