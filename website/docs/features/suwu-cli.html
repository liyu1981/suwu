Suwu CLI

suwu send posts notifications from any script. suwu forward opens a port-forwarding tile. suwu open resolves links and actions on the remote machine. Bridge your terminal and the web UI.

suwu send

Post a notification to the Suwu web UI from any terminal or script.

# Simple notification
suwu send "Build completed successfully"

# Pipe stdin as the notification body
echo "Tests passed" | suwu send

# With a title
suwu send --title "Deploy" "v2.1.0 deployed to production"

# Pipe a file
cat changelog.txt | suwu send --title "Changelog"

Notifications appear as a tile in the web UI with the title and body text. They persist until dismissed.

Use Cases

  • Build notifications — append suwu send "Build done" to your build script.
  • CI/CD alerts — pipe pipeline output to suwu send.
  • Monitoring — send alerts when a health check fails.
  • Long tasks — make && suwu send "Make complete".

suwu forward

Open a port-forwarding tile from the command line.

# Forward port 3000
suwu forward 3000

# Forward to a different remote port
suwu forward 8080:3000

# UDP forwarding
suwu forward --udp 5353

See Port Forwarding for full details.

suwu open

Open files, directories, or URLs in the Suwu web UI.

# Open a directory in the file browser
suwu open .

# Open a file in the viewer
suwu open README.md

# Open and watch for changes
suwu open --watch server.log

# Open a git graph
suwu open --git-graph .

# Open a diff
suwu open --diff old.go new.go

Options

Flag Description
--watch Auto-refresh when file changes
--git-graph Open as git graph
--diff Open as side-by-side diff
--tile TYPE Force a specific tile type

suwu update

Update the Suwu binary to the latest release:

suwu update

This downloads the latest release binary and replaces the current one. See Upgrading for details.

suwu auth

Manage authentication:

# Set a password
suwu auth password

# Clear the password
suwu auth clear

See Security & Access for full details.

Tip

Add suwu send to your .bashrc or .zshrc as a shorthand: alias done='suwu send "Done!"'. Then just run done when a task finishes.
