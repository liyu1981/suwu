Upgrading

Keep Suwu current with suwu update. The updater handles download, verification, and restart.

Update Commands

# Check for updates (without installing)
suwu update --check

# Install the latest version
suwu update

# Force update (even if already on latest)
suwu update --force

What the Updater Does

  • Downloads the latest release binary from GitHub.
  • Verifies the checksum to ensure integrity.
  • Replaces the current binary in-place at ~/.local/bin/suwu.
  • Restarts the server if it's running.
Note

The update replaces the binary at ~/.local/bin/suwu. Make sure this path is in your $PATH.

Version Check

See which version you're running:

suwu version

The version is also displayed in the web UI footer and in the server startup banner.

Staying Current Automatically

Add suwu update to a cron job or alias to stay current automatically:

# Check every Monday at 9am
0 9 * * 1 suwu update --check

# Or as a shell alias
alias sup='suwu update'

Configuration

Suwu stores its configuration in ~/.config/suwu/:

  • .env — environment variables (host, port, TLS paths).
  • theme.json — custom theme (optional).
  • sessions/ — persisted session data.

You can edit these files directly, or use the CLI and web UI settings panel. See Security & Data for details on what is stored and where.

CLI Reference

Command Description
suwu Start the server (runs onboarding if first time)
suwu serve Start the server (skip onboarding)
suwu onboard Run the onboarding process
suwu update Update to the latest release
suwu version Show the current version
suwu gencerts Generate self-signed TLS certificates
suwu auth password Set or change the web access password
