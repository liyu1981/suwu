Opening the DB Browser

The DB Browser is a tile like any other — open it alongside your terminals and other apps:

  • Context menu — right-click any tile and choose DB Browser.
  • Tile picker — create a new tile and select DB Browser from the app list.
  • Tile parameters — a new DB Browser tile accepts driver, host, port, and database parameters so a connection can be pre-filled when the tile is created.

Supported Databases

Driver Connection fields
SQLite Path to a .db file (including :memory:)
MySQL Host, port (default 3306), database, user, password, SSL mode
PostgreSQL Host, port (default 5432), database, user, password, SSL mode

SQLite needs no server — point the driver at a database file on the same machine, or use :memory: for a throwaway database. MySQL and PostgreSQL connect to a server reachable from the Suwu host.

Connecting

Pick a driver, fill in the fields, and press Connect. The connection is validated and the schema is loaded in one step; any error is shown inline in the dialog.

  • Recent connections — every successful connection is remembered (the last five per driver) and offered for one-click reconnect.
  • Saved connections — pick a recent connection to re-open it, or delete ones you no longer need.
Credentials

Passwords are used for the lifetime of the query session only. They are never written to disk and never included in a saved connection. A saved connection stores the driver, host, port, database, user, and SQLite path — but not the password.

Writing Queries

The SQL editor is a Monaco editor with SQL syntax highlighting. Type your statement and run it:

  • Run — press Ctrl+Enter (Cmd+Enter on macOS), or click Execute.
  • Status bar — shows the connection state, the row count, the execution time, and how many rows were affected.

Exploring Results

Query results render in a data table built for wide result sets:

  • Sort — click a column header to sort by that column; click again to reverse.
  • Page — results are paginated 100 rows at a time.
  • Inspect long values — long cells are truncated; click one to expand it.
  • Read NULLs — NULL values are dimmed and italic so they stand out from empty strings.
  • Export — download the current result set as CSV.

Schema Browser

The sidebar lists the tables and views in the connected database. Expand a table to load its columns.

  • Click a table to insert SELECT * FROM <table> LIMIT 100 into the editor.
  • Count rows from the table's context action to insert SELECT COUNT(*).
  • Resize — drag the divider between the schema panel and the editor.

Limits

Queries are bounded so a large result set can't take down the browser or the server:

Limit Value
Rows returned per query 10,000 — further rows are dropped and the result is marked truncated
Query timeout 30 seconds
Idle session timeout 30 minutes without activity, then the connection is closed

Keyboard Shortcuts

Action Shortcut
Execute query Ctrl+Enter / Cmd+Enter
Security

The DB Browser runs queries from the Suwu host with the credentials you provide. It does not widen Suwu's trust boundary — anyone who can reach the server already has a shell — but treat production databases with care: result sets are returned to the browser, where they can end up in a screenshot or a shared tab.

Tip

Keep a DB Browser tile next to a terminal tile for exploratory work: query in the browser, then copy the SQL into a script or migration when it's ready.
