Opening Dropbox

Open a Dropbox tile from the context menu on any tile, or create a new tile and switch its type to "Dropbox".

Uploading Files

  • Drag and drop files from your desktop directly into the Dropbox tile.
  • Click "Upload" to open a file picker dialog.
  • Multiple files — select multiple files in the picker, or drop a folder.

Files are uploaded to the current directory shown in the Dropbox tile. Navigate to a different directory before uploading to change the destination.

Downloading Files

  • Click any file in the listing to download it.
  • Right-click for options: download, view, or copy path.

Upload Progress

The Dropbox tile shows real-time upload progress for each file:

  • File name and size.
  • Progress bar with percentage.
  • Speed — current transfer rate.
  • Status — uploading, complete, or error.
Tip

Large files are chunked automatically. Upload a 1GB file and it'll resume if the connection drops mid-transfer.

Directory Upload

Drag a folder from your file manager into the Dropbox tile. The entire directory tree is uploaded, preserving the structure.

CLI Alternative

For scripted uploads, use suwu send with stdin:

# Upload a file via stdin
cat local-file.txt | suwu send --file remote-file.txt

# Upload from a script
tar czf - ./data | suwu send --file backup.tar.gz
