Security & Access

Access works out of the box on localhost, your LAN, or over the internet behind a reverse proxy — with password authentication, per-run tokens, and one-command HTTPS.

Access Levels

Suwu automatically detects where you're connecting from and applies the right level of access:

  • Localhost — no authentication required. Open http://127.0.0.1:8080 and go.
  • LAN — accessible from your local network. Password auth recommended.
  • Internet — behind a reverse proxy. HTTPS and strong auth required.

Password Authentication

Set a password during onboarding or anytime after:

# Set a password interactively
suwu auth password

# Or set it via environment variable
SUWU_PASSWORD=your-secret suwu serve

When a password is set, the web UI prompts for it on first access. Sessions are authenticated via a secure cookie.

Per-Run Tokens

For temporary access, Suwu generates a per-run token displayed in the terminal when the server starts. Share this token with someone who needs one-time access — it's valid only for the current server run.

$ suwu serve
  ┌──────────────────────────────────────┐
  │  Suwu is running                     │
  │  http://127.0.0.1:8080               │
  │  Token: abc123xyz                    │
  └──────────────────────────────────────┘
Note

Per-run tokens are displayed once at startup. If you miss it, restart the server to generate a new one.

HTTPS with One Command

Suwu can generate a self-signed certificate and enable HTTPS in one step:

# Generate certs and configure HTTPS
suwu gencerts

# The cert paths are written to ~/.config/suwu/.env
# Restart the server to pick them up
suwu serve

For production use, provide your own certificates:

TLS_CERT_FILE=/path/to/cert.pem \
TLS_KEY_FILE=/path/to/key.pem \
suwu serve

Reverse Proxy Setup

For internet access, put Suwu behind a reverse proxy (nginx, Caddy, etc.). The key headers to forward:

# nginx example
location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

Environment Variables

Variable Description
SUWU_PASSWORD Set password for web access
HOST Bind address (127.0.0.1 default, 0.0.0.0 for all interfaces)
PORT HTTP port (default: 8080)
TLS_CERT_FILE Path to TLS certificate
TLS_KEY_FILE Path to TLS private key
Tip

Browser-visible hostnames (localhost, LAN IP, machine hostname) are always accepted without extra configuration. You only need to set up certificates and reverse proxies for public internet access.
