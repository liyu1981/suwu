What You Get

Every terminal tile in Suwu is a real PTY-backed shell running on the server. It's not a simulation — it's your actual bash, zsh, or fish, with:

  • Full scrollback — scroll up through previous output with the mouse wheel or Shift+Page Up.
  • Text selection — click and drag to select, or double-click to select a word, triple-click for a line.
  • Copy/paste — Ctrl+Shift+C to copy, Ctrl+Shift+V to paste. Also works with your system clipboard.
  • Unicode & emoji — full Unicode support including wide characters and emoji.
  • True color — 24-bit color for modern terminal tools.

Session Persistence

Terminal sessions persist across page refreshes and disconnections. When you reconnect, Suwu restores:

  • The shell process (it kept running while you were away).
  • The visible scrollback buffer.
  • The working directory and environment.
Tip

Long-running processes (builds, tests, ssh sessions) continue even when your browser is closed. Reconnect and pick up where you left off.

Notifications

When a terminal produces output while it's not focused, Suwu shows a visual indicator on the tile. This is useful for:

  • Long builds that finish while you're working in another tile.
  • suwu send notifications from scripts.
  • Background jobs completing.

Agent Integration

Suwu terminals are designed to work with agent orchestrators like opencode, pi, and herdr. Each terminal is a real PTY that agents can read from and write to, with proper signal handling and output streaming.

Shell Selection

Suwu uses your default login shell. To change it, set the SHELL environment variable before starting the server, or configure it during onboarding.

# Use zsh instead of bash
SHELL=/bin/zsh suwu serve
