Overview

Suwu renders a full-viewport background behind the tile grid. It is chosen in System Settings → Appearance and stored per browser, so the shell, the tiles, and the background all come back the way you left them.

Backgrounds are pluggable: each declares its own tunable parameters, and some ship both a CPU and a WebGPU implementation. Suwu picks the GPU one when your browser supports WebGPU and falls back to the CPU one when it does not. A GPU-only background simply renders nothing on a browser without WebGPU.

Choosing a Background

Open Settings (Ctrl+,) and switch to the Appearance tab:

  • Live preview — a small preview above the selector shows exactly what the selected background looks like, sized to the current window's aspect ratio. It updates as soon as you change the selection or a parameter.
  • Primary selector — lists the backgrounds available to the shell. Engine-backed shader backgrounds are grouped under a single WebGPU entry.
  • WebGPU selector — when the WebGPU group is selected, a second selector chooses which engine background to run.
  • Credit — backgrounds ported from external work show the author, a link, and any license note below the preview.
WebGPU availability

WebGPU requires a secure context (HTTPS or localhost) and a supporting browser. GPU-only backgrounds show a Preview needs WebGPU note when it is unavailable. Everything else keeps working — the shell falls back to a CPU background.

Per-Background Settings

Each background controls its own parameters, shown below the selector. Common ones include:

  • Palette — Ambient Blob can match the active theme or force a light or dark palette.
  • Animation speed — scales the motion of a shader background.
  • Detail — caps the shader render budget in megapixels (Low / Medium / High / Ultra / Native), trading sharpness for GPU cost.
  • Colour and opacity — tint controls, such as the mask drawn over a video.

A parameter change restarts the backend so the new value takes effect. Shader backgrounds share one animation clock, so changing a parameter does not snap the animation back to the start.

Video Clips

The Video background plays short, muted clips without a network round trip:

  • Upload — pick MP4, WebM, or Matroska files. Each clip is copied into this browser's private storage (OPFS) with a thumbnail, so it stays available across reloads and is never uploaded to the server.
  • Fit — Auto-crop (cover) fills the viewport and crops the overflow, or Stretch to fill distorts the clip to the viewport.
  • Playback speed — from 0.25× to 2×.
  • Smooth loop — crossfades the last two seconds into the start to hide the jump at the loop point. Off by default and skipped for clips shorter than four seconds.
  • Mask — a colour and opacity tint drawn over the video. The default is the same translucent white as the tile panel, so the tiles stay readable.

Clips longer than 30 seconds are flagged as too long for a background. Decoding is done lazily with backpressure, so memory stays bounded regardless of clip length; load and codec failures are reported on the canvas itself.

Performance

  • WebGPU first — when the browser and context support it, Suwu runs the GPU backend and moves the work off the main thread.
  • CPU fallback — Ambient Blob and Video have canvas-based backends that keep rendering without WebGPU. The CPU path is frame-capped and pauses while the tab is hidden or the window is blurred.
  • Reduced motion — when prefers-reduced-motion: reduce is set, backgrounds settle to a static frame instead of animating.
  • Detail caps — shader backgrounds render to a bounded megapixel budget, so a 4K viewport does not cost proportionally more.

Debug Overrides

To force a backend for testing, append a query parameter to the URL:

?bg=gpu    # force the WebGPU backend
?bg=cpu    # force the CPU fallback
?bg=auto   # automatic (default)

You can also persist a choice with localStorage.setItem('suwu.bg', 'cpu'). The background itself is always chosen in System Settings.

Tip

A subtle CPU-friendly background keeps the interface fast on low-power machines. Use the live preview to judge a choice before committing, and dial the tile glass alpha up if a busy background hurts readability.
