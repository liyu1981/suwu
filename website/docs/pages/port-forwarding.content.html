Quick Start

Forward a port from a terminal using the suwu forward command:

# Forward local port 3000 to remote port 3000
suwu forward 3000

# Forward to a different remote port
suwu forward 8080:3000

# UDP forwarding
suwu forward --udp 5353

This opens a new tile showing the forwarding status with connection count and traffic stats.

How It Works

When you run suwu forward, the server opens a listener on the specified port and proxies traffic to the target. The tile shows:

  • Port — the port being forwarded.
  • Protocol — TCP or UDP.
  • Connections — active connection count.
  • Traffic — bytes transferred in/out.
  • Status — active, paused, or error.

Managing Forwards

From the port forward tile, you can:

  • Pause — temporarily stop accepting new connections.
  • Close — stop forwarding and close the tile.
  • View logs — see connection events and errors.

Use Cases

  • Dev servers — forward a Node.js/Go dev server to access it from your local browser.
  • Database access — connect to a remote PostgreSQL/MySQL from a local client.
  • API testing — expose a local API running on the remote machine.
  • SSH tunneling — as an alternative to ssh -L with better visibility.
Tip

Forward multiple ports simultaneously — each suwu forward call creates a separate tile. Monitor all your services at a glance.

CLI Reference

Command Description
suwu forward PORT Forward PORT to the same port on remote
suwu forward LOCAL:REMOTE Forward LOCAL port to REMOTE port
suwu forward --udp PORT UDP forwarding instead of TCP
suwu forward --bind ADDR PORT Bind to a specific address (default: all interfaces)
