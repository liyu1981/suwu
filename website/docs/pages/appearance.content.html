Opening Settings

Click the gear icon in the header, or press Ctrl+, to open the settings panel.

Font Settings

  • Font family — choose from system fonts or web fonts. Defaults to Inconsolata for terminals.
  • Font size — adjust from 10px to 24px. The setting applies to all terminal tiles.
  • Line height — fine-tune spacing between lines.
# Via environment variable
SUWU_FONT_SIZE=14 suwu serve

# Font family
SUWU_FONT_FAMILY="Fira Code" suwu serve

Theme

Suwu includes several built-in themes:

  • Light — clean, bright theme (default).
  • Dark — easy on the eyes for night coding.
  • Solarized Light / Dark — the classic Solarized palette.
  • Dracula — popular dark theme with vibrant colors.
  • Custom — define your own color palette.

Glass Alpha

Control the transparency of the tile backgrounds:

  • 0% — fully opaque solid background.
  • 50% — semi-transparent, shows the background canvas.
  • 100% — fully transparent (glass effect).

Adjust with the slider in settings, or via environment variable:

# 30% transparency
SUWU_GLASS_ALPHA=0.3 suwu serve
Tip

The glass alpha setting interacts with your desktop wallpaper. A subtle alpha (0.1–0.3) gives depth without sacrificing readability.

Language

Suwu supports English and Chinese (Simplified) out of the box. The interface detects your browser's language preference automatically.

To force a language:

# Force English
SUWU_LANG=en suwu serve

# Force Chinese
SUWU_LANG=zh suwu serve

You can also switch languages from the settings panel — the change takes effect immediately.

Custom Themes

Create a custom theme by defining color tokens:

# In ~/.config/suwu/theme.json
{
  "name": "My Theme",
  "colors": {
    "background": "#1a1b26",
    "foreground": "#c0caf5",
    "cursor": "#c0caf5",
    "black": "#15161e",
    "red": "#f7768e",
    "green": "#9ece6a",
    "yellow": "#e0af68",
    "blue": "#7aa2f7",
    "magenta": "#bb9af7",
    "cyan": "#7dcfff",
    "white": "#a9b1d6"
  }
}

Place the file at ~/.config/suwu/theme.json and it will appear in the theme selector.
